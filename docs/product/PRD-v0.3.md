## 一、产品概述

### 1.1 产品定位
「小确幸」是一款以**植物生长**为核心意象的生活记录 App。用户通过记录生活瞬间（文字/照片/音频/音乐/地点/链接/心情）浇灌属于自己的「幸福植物」，记录越丰富、越坚持，植物生长越茂盛；支持**分享外部内容链接**（微信/小红书/B站/知乎等）和**附音乐**（网易云/QQ音乐/Spotify/Apple Music），让记录不只是自己写，还能收藏打动自己的外部内容；同时支持情侣、家人、朋友之间的**共享空间**，共同培育一棵「合种之树」。最终产品为 **Android 原生应用**，前期以 Web Demo 形式进行交互与视觉验证。

### 1.2 核心价值主张
- **记录即滋养**：将抽象的"幸福感"具象为看得见的生长，降低记录门槛，增强坚持动力
- **情感可视化**：用植物形态变化承载情绪记忆，打开 App 就能看见"自己最近过得怎么样"
- **亲密关系共建**：共享空间让关系有了共同生长的载体，不只是各记各的
- **轻量无负担**：区别于日记 App 的"写长文"压力，小确幸鼓励"拍一张、标个心情、留个地点"的碎片记录
- **回忆可翻阅**：电子画册将点滴记录自动汇编成精致可翻阅的纪念册，让幸福有了实体般的质感

### 1.3 目标用户
| 用户画像 | 典型场景 | 核心诉求 |
|---------|---------|---------|
| 18-30岁年轻女性为主 | 旅行打卡、美食记录、恋爱日常 | 好看、能分享、有仪式感 |
| 情侣/夫妻 | 异地恋、纪念日、共同生活记录 | 私密共享空间、互动反馈 |
| 情绪敏感/正念练习者 | 记录开心瞬间对抗低落 | 正向心理暗示、心情回顾 |
| 亲子家庭 | 记录孩子成长瞬间 | 家人共享、长期保存 |

### 1.4 差异化对比
| 维度 | 小确幸 | 日记类（Day One/格志） | 打卡类（小日常/番茄） | 社交类（小红书/朋友圈） |
|------|--------|---------------------|-------------------|---------------------|
| 核心意象 | 植物生长+电子画册 | 日记本 | 习惯养成 | 内容广场 |
| 记录压力 | 极低（碎片可记） | 中（需要文字） | 低（打卡即可） | 中（需要经营形象） |
| 社交形态 | 私密共享（小圈子） | 基本无 | 基本无 | 公开/半公开 |
| 激励机制 | 植物生长+成就解锁+画册回顾 | 连续天数 | 连续打卡 | 点赞评论 |
| 数据所有权 | 个人/小圈子 | 个人 | 个人 | 平台 |

### 2.2 核心用户流程

#### 流程1：快速记录一条小确幸
```
打开App → 首页植物视图 → 点击「+」快速记录
  → 选择内容类型（文字/照片/音频/地点可组合）
  → 选择标签（心情必选？状态可选，可自定义）
  → 选择记录到哪个空间（默认上次）
  → 发布
  → 触发植物生长动画（水滴/阳光/生长特效）
  → 如触发成就，播放解锁动画
  → 回到首页，植物已更新状态
```

#### 流程2：创建共享空间（情侣空间为例）
```
我的 → 空间管理 → 创建共享空间
  → 选择植物种子类型（情侣树/家庭树/友谊树等）
  → 设置空间名称（如"我们的小日子"）
  → 邀请对方（二维码/链接/通讯录）
  → 对方接受后，合种开始
  → 双方任一记录都会滋养同一棵植物
  → 可查看"谁浇了多少水"贡献统计
```

#### 流程3：回顾美好
```
首页植物 → 点击植物/时间线入口
  → 按时间浏览历史记录
  → 或切换地图视图看地点分布
  → 或切换心情统计看情绪变化
  → 点击单条记录可查看详情
  → 月度/年度自动生成回顾卡片（可分享）
```

#### 流程4：生成并翻阅电子画册
```
首页/回顾入口 → 点击「电子画册」
  → 选择画册生成范围（全部历程 / 指定生长阶段，如"发芽→幼苗期"）
  → 系统自动汇编画册（封面→时间轴→心情→标签→地点→回顾页）
  → 进入翻阅模式：左右滑动/点击翻页，带翻页动画
  → 可随时点击「导出」→ 选择图片长图 / PDF
  → 分享到微信/保存到相册
```

## 三、功能详细设计

### 3.1 记录模块

#### 3.1.1 记录内容类型
| 类型 | 必填 | 说明 | 上限 |
|------|------|------|------|
| 文字 | 否（与其他至少一项组合） | 自由文本，支持表情 | 500字 |
| 照片 | 否 | 本地相册/拍照，支持多选 | 9张 |
| 语音 | 否 | 录制语音片段，记录当下的声音/感慨 | 60s |
| 音乐 | 否 | 分享歌曲：搜索音乐库或粘贴音乐平台分享链接（网易云/QQ音乐/Spotify/Apple Music），自动解析歌名、歌手、专辑封面 | 1首 |
| 链接 | 否 | 分享外部内容链接（微信文章/小红书/B站/知乎/抖音/微博/YouTube/新闻等），自动解析平台、标题、摘要、封面图 | 1条 |
| 地点 | 否 | 自动定位/搜索选择/手动输入 | 1个 |
| 标签 | **是（心情标签必选）** | 心情标签+状态标签+自定义标签 | 心情1个必选，其他合计最多5个 |
| 时间 | 自动 | 记录时间（默认当前，可修改为过去时间补记） | - |

> 设计原则：文字非必填，降低"写不出东西"的压力。只拍一张照片+标个心情也可以。

#### 3.1.2 标签系统
**心情标签**（必选1个，多选1-2个）：
- 开心😊 感动🥹 平静😌 兴奋🤩 满足😌 温暖🥰 惊喜😲 放松😎 想念🤍 感恩🙏
- （可后续扩展）低落时也可记，但不鼓励——可设"今天有点难"标签，植物不会枯萎，但会显示需要关爱

**状态标签**（可选）：
- 旅行✈️ 美食🍜 运动🏃 阅读📖 工作💼 学习📝 约会💕 家人👨‍👩‍👧 朋友👥 宠物🐱 自然🌿 电影🎬 音乐🎵 独处🌙 早起🌅 健身💪 购物🛍️ 发呆💭

**自定义标签**：用户可创建个人标签，最多20个。共享空间内自定义标签空间成员可见可选。

#### 3.1.3 补记功能
支持选择过去的日期时间补记（最多往前补365天）。补记同样浇灌植物，但生长值有轻微衰减（补记×0.8），鼓励即时记录。

### 3.2 植物生长系统

#### 3.2.1 植物生长逻辑
这是 App 的核心游戏化机制：

**生长值（Growth Points, GP）计算**：
```
单条记录GP = 基础值 + 内容丰富度加成 + 连续性加成 + 特殊事件加成

基础值：10 GP（任意一条有效记录）
内容加成：
  - 有文字：+5（>50字再+5）
  - 有照片：每张+3（最多+27）
  - 有语音：+5
  - 有音乐：+5
  - 有链接：+5
  - 有地点：+3
  - 有状态标签：每个+2（最多+6）
连续性加成：
  - 连续记录N天：× (1 + N×0.05)，上限×2（即连续20天翻倍）
  - 中断后连续天数重置
特殊事件加成：
  - 纪念日/生日等预设日期记录：+20
  - 节日当天记录：+10
  - 共享空间双方同日记录：+15（合种共振）

每日GP上限：100（防止刷分，但一条丰富记录基本能到50-70）
```

#### 3.2.2 植物形态阶段
| 阶段 | GP范围 | 形态描述 | 视觉表现 |
|------|--------|---------|---------|
| 种子 | 0-50 | 土里一颗种子，偶尔微微颤动 | 静态图+微弱呼吸动效 |
| 发芽 | 50-200 | 破土而出，两片小嫩芽 | 轻微摇摆动画 |
| 幼苗 | 200-500 | 长出茎和几片叶子 | 有微风时摇曳 |
| 成长 | 500-1500 | 明显长高，叶片增多 | 定期有蝴蝶/萤火虫经过 |
| 茂盛 | 1500-4000 | 枝繁叶茂，可能开花 | 花朵绽放动画、花瓣飘落 |
| 大树 | 4000-10000 | 完整树木，可结果 | 果实悬挂、光影变化 |
| 神木 | 10000+ | 持续生长，季节变化 | 四季皮肤切换、特殊天气效果 |

> **植物种类系统**：用户可以选择不同植物作为"幸福载体"，不同植物外观风格和阶段形态差异巨大，但GP生长逻辑一致。植物种类是App重要的个性化和收集玩法。

#### 3.2.2a 植物种类详解
| 植物 | 解锁条件 | 色系 | 7阶段形态特点 | 特殊动效 |
|------|---------|------|------------|---------|
| 🌳 小确幸之树 | 默认解锁 | 翠绿 | 种子→嫩芽→幼苗→枝叶茂盛→开花→结果→神木 | 蝴蝶/萤火虫、落叶、四季变化 |
| 🌸 樱花树 | 连续记录30天 | 粉色 | 种子→嫩芽→小树→绿叶成荫→满树粉花→花瓣飘落→樱花林 | 花瓣持续飘落、春风特效 |
| 🌻 向日葵 | 默认解锁 | 金黄 | 种子→发芽→长高→花苞→大花盘绽放→花盘随光转→向日葵田 | 花盘跟随动画、阳光粒子 |
| 🌵 仙人掌 | 在50个地点记录 | 沙漠绿 | 孢子→小芽→圆球→长刺→分节→开彩色小花→仙人掌群 | 沙漠背景、星辰夜晚 |
| 🪴 多肉 | 累计记录100条 | 果冻绿/粉 | 种子→单片叶→小莲座→饱满莲座→群生→变色→爆盆 | 水珠/露珠、Q弹弹性动画 |
| 🌿 藤蔓 | 邀请1位好友合种 | 翠绿 | 种子→嫩芽→长出藤蔓→攀爬延伸→缠绕→开花→藤蔓森林 | 藤蔓攀爬屏幕边缘 |
| 🌹 玫瑰花丛 | 情侣空间专属/会员 | 红/粉 | 种子→嫩芽→灌木→花苞→玫瑰绽放→花丛→玫瑰花园 | 花瓣、蝴蝶、爱心粒子 |
| 🎋 竹林 | 累计记录365天 | 墨绿 | 竹笋→小竹→拔节长高→成竹→竹叶飘落→竹林→竹海 | 风吹竹林沙沙、竹叶飘落 |
| 🍄 蘑菇 | 隐藏成就解锁 | 奇幻多彩 | 孢子→小白菇→长大→变色→蘑菇群→蘑菇圈→奇幻蘑菇森林 | 精灵光点、荧光特效 |

**植物切换规则**：
- 每个空间同时只能养一棵植物
- 更换植物时可选择：①新植物从头开始生长（GP清零，旧植物数据保存到图鉴）②GP迁移（新植物从当前GP对应的阶段开始，但需要消耗道具"营养土"）
- 更换下来的植物进入「植物图鉴」，可随时查看过往养殖记录
- 共享空间的植物种类由创建者选择，成员可投票更换

#### 3.2.2b 植物图鉴
- 入口：我的页面 → 植物图鉴
- 展示所有植物种类，已解锁的彩色展示+养殖记录（养了多久/最高阶段/记录数），未解锁的灰色+解锁条件
- 每种植物点击可查看各阶段形态预览（类似宝可梦图鉴）
- 集齐所有植物获得"植物学家"隐藏成就

#### 3.2.3 植物不会枯萎
重要设计决策：**植物不会因为不记录而枯萎或降级**。原因：
1. 避免愧疚感导致用户流失（"好久没记了，不敢打开"是很多习惯类App的死因）
2. 符合"小确幸"的积极心理学定位
3. 但连续中断后植物会显示"需要关爱"状态（轻微视觉变化，如叶子略卷），回归记录后立即恢复

### 3.3 共享空间

#### 3.3.1 空间类型
| 类型 | 人数 | 初始植物 | 典型场景 |
|------|------|---------|---------|
| 个人空间 | 1 | 小确幸之树（默认） | 自己的小世界 |
| 情侣空间 | 2 | 情侣树/樱花树 | 恋爱记录、异地恋 |
| 家庭空间 | 2-6 | 家庭树/苹果树 | 亲子成长、家庭日常 |
| 好友空间 | 2-10 | 友谊树/向日葵 | 闺蜜日常、旅行搭子 |

每个用户可以有：1个个人空间（免费）+ N个共享空间（免费3个，更多需会员）。

#### 3.3.2 合种机制
- 所有成员的记录都滋养同一棵植物，GP累计
- 可查看成员贡献度（"本月TA浇灌了60%"），但不排名、不竞争
- **合种共振**：同一日两人都记录，触发+15GP加成+特殊动画（如爱心/星光特效）
- **互动**：可以给对方的记录点赞/评论（仅空间内可见）
- **纪念日提醒**：可设置共同纪念日，当天自动提醒双方记录

#### 3.3.3 隐私控制
- 个人空间记录完全私密
- 共享空间内记录对成员可见
- 分享到外部（微信/朋友圈等）需用户主动操作，不自动同步
- 退出共享空间后，个人记录可带走，合种植物留在空间（或由创建者处理）

### 3.4 成就系统

#### 3.4.1 成就类型
**里程碑成就（必达）**：
| 成就名 | 条件 | 奖励 |
|--------|------|------|
| 第一滴水 | 记录第一条小确幸 | 种子发芽动画+50GP |
| 七日之约 | 连续记录7天 | 解锁"藤蔓"植物种 |
| 满月纪念 | 连续记录30天 | 解锁"月夜"皮肤+100GP |
| 百日耕耘 | 连续记录100天 | 解锁"樱花树"+专属徽章 |
| 小确幸大师 | 累计记录365天 | 解锁"神木"阶段+年度回顾特辑 |
| 繁花似锦 | 单条记录获得50+GP（超丰富记录） | 特殊花朵装饰 |
| 行走的地图 | 在50个不同地点记录 | 地图皮肤+地标装饰 |

### 3.6 电子画册系统（核心功能）⭐

电子画册是小确幸 App 的差异化核心功能，将用户的植物生长历程和日常记录自动汇总为一本可翻阅、可分享的精致电子画册，呈现**精致杂志/手账风**排版。

#### 3.6.1 画册入口
- 首页植物视图增加「画册」快捷入口（植物旁的书本图标）
- 回顾模块顶部增加「生成电子画册」入口
- 植物阶段升级时，弹窗提示「生成新画册回顾成长历程」

#### 3.6.2 画册封面
封面元素构成：
- **主体**：植物当前形态插画（带呼吸微动效）
- **标题**：「我的小确幸画册」（艺术字体）
- **副标题**：用户名（如"小明的幸福时光"）
- **统计**：「共 XX 个幸福瞬间」（XX为该空间/范围内记录总数）
- **装饰**：花瓣/叶子等植物元素点缀，与植物种类主题色一致
- **可选**：选择特定阶段生成时，显示阶段名称（如"发芽到幼苗期"）

#### 3.6.3 自动分页结构
画册由以下固定页面类型自动拼装，页数根据记录量动态调整：

| 页码 | 页面类型 | 内容说明 | 排版风格 |
|------|---------|---------|---------|
| 1 | 封面 | 上述封面元素 | 居中对称，大留白 |
| 2 | 植物生长时间轴页 | 从种子到当前阶段的生长变化，时间轴展示各阶段解锁日期+植物缩略形态，标注重要里程碑（如"第7天发芽""第30天开花"） | 纵向时间轴，左侧阶段图标+日期，右侧简述 |
| 3-4 | 心情合集页 | 按心情标签聚合展示，每种心情选取代表照片1-2张+精选文字片段，统计各类心情占比（如"本月开心占75%"） | 拼贴风格，心情色块分区 |
| 5-6 | 标签精选页 | 按状态标签分类展示精选记录（旅行/美食/家人等），每个标签选3-5条最具代表性的记录（优先选有照片、文字丰富的） | 网格卡片，标签色为主题色 |
| 7 | 地点地图页 | 带地点记录的地图标记，标注去过的地方数量，常去地点Top3展示照片缩略图 | 全幅地图底+地点卡片浮层 |
| 7b | BGM配乐页 | 如果范围内有音乐记录，展示「这段时光的BGM」页面：所有记录过的歌曲以音乐播放列表形式排列（专辑封面+歌名+歌手+记录日期），排版类似音乐App歌单，营造"给这段日子配乐"的仪式感 | 暗色歌单风，封面网格+歌曲列表 |
| 7c | 精选链接页 | 如果范围内有外部链接记录，展示「值得收藏」页面：精选的外部内容卡片（文章/视频/笔记等），以杂志书签卡片形式排版，保留平台标识 | 杂志书签卡片风，错落排列 |
| 8-N | 月度/阶段回顾页 | 按月或阶段聚合精选瞬间，瀑布流/拼贴画风格展示照片+文字，每月/阶段2-4页不等 | 杂志拼贴风，大小图错落，手写体标注日期/地点 |
| 末页 | 封底 | "幸福还在生长…"+当前植物形态+二维码（分享时扫码下载App） | 简洁收尾 |

#### 3.6.4 画册生成范围选择
用户在生成前可选择画册覆盖范围：
- **全部历程**：从第一条记录到现在，生成完整画册
- **按生长阶段**：选择起止阶段，如"种子→发芽"、"发芽→幼苗期"、"茂盛→大树期"
- **按时间范围**：选择自定义起止日期
- **快捷选项**：「最近一个月」「最近三个月」「今年」

#### 3.6.5 翻页交互
- **左右滑动翻页**：模仿真实翻书的滑动手势，带书页弯曲翻页动画
- **点击翻页**：点击屏幕右半部分下一页，左半部分上一页
- **页边拖拽**：从页面边缘拖拽可预览下一页内容（类似iBooks效果）
- **底部页码指示器**：显示当前页/总页数，点击可跳页
- **目录页**：点击页码弹出目录，快速跳转到指定章节
- **全屏沉浸**：浏览时隐藏状态栏，纯画面体验
- **双击/捏合**：可放大查看照片细节

#### 3.6.6 视觉风格规范
- **整体风格**：精致杂志 + 手账风混搭，温暖治愈系
- **配色**：基于植物当前阶段的主题色（种子期-暖棕色系、发芽期-嫩绿色系、茂盛期-翠绿色系、开花期-粉色系等）
- **字体**：标题用衬线/手写艺术字体，正文用清晰易读的无衬线字体
- **装饰元素**：胶带贴纸感边框、手绘分割线、花瓣/叶片散落装饰、日期印章效果
- **照片处理**：轻微圆角+阴影，部分照片带拍立得白边效果，偶尔有倾斜角度增加手账感
- **背景纸张纹理**：淡雅的纸张/水彩底纹，不喧宾夺主

#### 3.6.7 分享与导出
- **导出为图片**：
  - 单页分享：当前页导出为一张竖版图片（带App水印）
  - 长图分享：整本画册拼接为长图（超长图分页提示）
  - 九宫格切图：自动将画册切为3×3九宫格，适合朋友圈发布
- **导出为PDF**：
  - 高清排版PDF，保留矢量文字和高清图片
  - 适合打印或发送给朋友
- **直接分享**：调用系统分享面板，支持分享到微信/QQ/微博等
- **保存到本地**：保存到手机相册/文件管理器

**展示样式**：链接卡片（封面图在左或上，标题+来源+描述在下），在记录详情页和时间线卡片中展示。
**交互**：点击卡片在App内WebView打开或跳转外部浏览器。
**GP加成**：有链接 +5GP

#### 3.1.6 记录页面完善设计
**添加按钮区**：一排圆形图标按钮（照片🎤/语音/🎵音乐/🔗链接/📍地点），按钮有精致的hover/press动效，已添加的类型在单条限制内变灰禁用（音乐/链接/地点/语音仅1个，照片最多9张）。

**已添加内容预览区**：
- **照片**：缩略图网格排列，点击大图预览，右上角X删除，支持拖拽排序
- **音乐**：深色音乐卡片（专辑封面+歌名+歌手+播放按钮），右上角X删除
- **链接**：链接预览卡片（封面+平台icon+标题+摘要），右上角X删除
- **地点**：地点卡片（小地图缩略图+地名+地址），支持点击修改位置
- **语音**：语音条（波形图+时长+播放/暂停按钮），支持删除/重录
- 所有卡片统一视觉：圆角12-16px，柔和阴影，间距一致，右上角统一删除按钮位置

**记录编辑能力**：发布前可随时添加/删除/修改内容；发布后24小时内可编辑。

#### 3.1.7 记录分享功能
分享是小确幸重要的获客和传播入口，每条记录都可以生成精美的分享卡片。

**入口**：
- 记录详情页右上角「分享」按钮
- 时间线卡片长按/右上角菜单中「分享」
- 首页最近一条记录旁的快捷分享按钮
- 电子画册可分享整本或单页

**分享卡片自动生成**：
根据记录内容自动排版生成竖版精美图片（1080×1920，适配朋友圈/小红书/Ins）：
- 顶部栏：植物小图标 + "小确幸" + 日期（如"2026.08.26"）
- 核心内容区（根据内容智能排版）：
  - 心情emoji大图标突出展示在醒目位置（如左上角大emoji+心情文字）
  - 文字内容：优雅排版，长文自动截断加"..."
  - 照片：1张全屏/2张对半/3张三拼/4张网格/5张以上选3张主图+more标记
  - 音乐条：底部横条（专辑封面小图+歌名+歌手+"♪"音符装饰）
  - 链接：链接小卡片样式
  - 地点：小地图pin+地名
- 底部栏：植物当前形态小图 + 二维码（占位） + Slogan"用小确幸记录生活"
- 配色根据当前植物主题色和心情标签调整（开心用暖色/平静用绿调/想念用蓝调）
- 装饰元素：根据植物种类加花瓣/叶片/星星/光斑等装饰
- 风格统一：治愈系、手账感、大圆角、温暖字体

**分享渠道**：
- 分享到微信好友/朋友圈/微博/小红书/QQ
- 复制分享链接
- 保存图片到本地相册
- 系统分享Sheet（Android原生分享面板）

**分享到小确幸（系统分享接入）**：
- Android系统分享菜单中出现"小确幸"入口
- 从其他App分享文字/URL/图片/音乐链接到小确幸时，自动打开新建记录页面，预填充对应内容
- 这是重要的获客入口，用户不需要打开App就能快速记录

**分享追踪**：
- 分享带来新用户注册时，记录来源（哪条记录/哪个用户分享）
- 分享成就："分享达人"（分享10次）、"传播幸福"（分享带来5个新用户）
